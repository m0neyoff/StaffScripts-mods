## 📖 О проекте

**StaffScripts** — это мощный набор модов/плагинов для администрации Minecraft серверов (версия 1.21.4).  
Он позволяет автоматизировать рутинные задачи модерации, выдавать наказания, отслеживать действия игроков и управлять сервером через удобные скрипты и GUI-интерфейсы.

### Инструкция по установке

1. **Скачайте архив** по ссылке выше.
2. Распакуйте `.rar` архив с помощью WinRAR, 7-Zip или аналогичного софта.
3. Внутри вы найдете файл с расширением `.jar`.
4. Поместите `.jar` файл в папку `mods` клиента Minecraft Fabric
5. Перезапустите игру.
